# ⚡ Sammy Analytics AI

Sammy Analytics AI is an intelligent, conversational data analysis web application built with Python and Streamlit. It allows users to upload raw CSV datasets and interact with them using natural language. 

Powered by the Groq API (gpt-oss-20b), the application dynamically writes and executes Pandas and Plotly code in a secure sandbox to generate insights, text summaries, and interactive visualizations on the fly.

## 🚀 Features
*   **Conversational Interface:** Ask plain-English questions about your data.
*   **Interactive Visualizations:** Automatically generates Plotly interactive charts and Matplotlib static graphs.
*   **Data Explorer:** Inspect raw data and export cleaned CSVs directly from the UI.
*   **Automated AI Summary:** One-click executive summary of data structure, quality, and suggested analytical queries.
*   **Transparent Execution:** View the exact Python code generated and executed by the AI for every query.

## 🛠️ Tech Stack
*   **Frontend:** Streamlit
*   **Data Manipulation:** Pandas
*   **Visualization:** Plotly, Matplotlib, Seaborn
*   **LLM Engine:** Groq API (gpt-oss-20b)
